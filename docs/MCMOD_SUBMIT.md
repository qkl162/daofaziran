## 三、详细正文（可直接粘贴，Markdown）

### 简介

**道法自然（FuLu）** 是一个面向 Minecraft 1.20.1 的**修仙向符箓模组**。

核心玩法是三步：**画符 → 布阵 → 猎妖丹**。

用黄纸与朱砂合成符纸，把不同的符装进「阵眼」，就得到一个持续生效的阵法；在「炼妖阵」里击杀怪物会掉落对应的「妖丹」，把妖丹放进「妖丹匣」后，它就变成了你的技能栏。

### 一、符与阵

| 物品 | 用途 |
|---|---|
| 符纸 | 基础材料，用于合成各种符 |
| 阵眼 | 放下后右键装入符，此时阵法开始生效 |
| 朱砂 | 合成材料 |

**14 种阵法**：

| 阵法 | 效果 |
|---|---|
| 乱神阵 | 范围内的怪物互相攻击 |
| 飞剑阵 | 召唤飞剑持续穿刺 |
| 反重力阵 | 区域内重力反转 |
| 替身阵 | 致命伤害由替身承受 |
| 移祸阵 | 把受到的伤害转嫁给怪物 |
| 召唤阵 | 召唤阵仆作战 |
| 打滑阵 | 区域内实体无法站稳 |
| 无明阵 | 致盲，怪物看不见玩家 |
| 闭环阵 | 怪物被限制在阵法边界内 |
| 咫尺天涯阵 | 锁定距离，怪物走不进来 |
| 水墨阵 | 视觉与屏障效果 |
| 时缓阵 | 减速怪物、限制攻击频率 |
| 炼妖阵 | 击杀怪物掉落妖丹 |
| 空阵 | 未装符状态 |

### 二、妖丹与技能

妖丹装进**妖丹匣**（6 格）后作为技能使用。每颗妖丹有独立冷却，多技能妖丹的每个技能也各自计算冷却。

**按键**：

| 按键 | 作用 |
|---|---|
| `R` | 打开妖丹轮盘，选择生物能力 |
| `V` | 选择当前妖丹的具体技能 |
| `Z` | 释放当前技能 |

**10 种妖丹**：

| 妖丹 | 技能 |
|---|---|
| 僵尸妖丹 | 绝仙瘴气：持续伤害 + 剥离全部增益 + 禁疗 |
| 骷髅妖丹 | 追踪箭：射出的箭自动锁定视野内目标 |
| 苦力怕妖丹 | 自爆：不破坏地形 |
| 蜘蛛妖丹 | 盘丝天牢（法则级禁锢：剥夺 AI、吊起 2 格、护甲归零、每秒真伤、笼内施法触发湮灭）/ 蛛行（爬墙开关） |
| 末影妖丹 | 虚空放逐：与准星目标互换位置；目标血量低于 20% 时直接抹除并为主角回血 |
| 烈焰妖丹 | 九幽冥火：慢速追踪火球，命中施加「阴火」状态（每秒 3% 最大生命真伤 + 攻击反伤） |
| 女巫妖丹 | 诡计毒瓶：抛掷滞留毒瓶，毒伤每秒结算 4 次 |
| 史莱姆妖丹 | 粘液沼泽：三倍重力、跳起摔伤；玩家对泥沼内目标必定暴击 |
| 凋零骷髅妖丹 | 光翼连斩：2 秒三段扇形剑气，破甲 / 禁疗 / 30% 处决 / 第三斩破盾 |
| 恶魂妖丹 | 陨石天降（30 秒冷却，落点预警 1.5 秒后降临）/ 恶魂飞行（开关） |

### 三、阵魔 Boss

一个拥有多阶段、必杀技与处决机制的自定义 Boss：

- 血量降低后进入第二、第三阶段，移速与攻击节奏提升
- 周期性无敌护盾，期间需要打满次数才能破防
- 必杀技：血量归零前会先手「处决」，玩家需要靠图腾、无敌或替身来抵抗
- 有专属 Boss 血条与出场/阶段音效

### 四、安装

1. 安装 Minecraft Forge 47.x（1.20.1）
2. 把 **GeckoLib 4.x** 放进 `mods/`
3. 把 `fulu-1.0.0.jar` 放进 `mods/`
4. 启动游戏

### 五、已知限制

- 目前只有 3 个妖丹拥有多技能（蜘蛛、恶魂、凋零骷髅），其余为单技能
- 部分技能特效为自定义几何渲染，关闭「粒子效果」不会影响主体表现，但会减少装饰粒子
- 英文版与中文版共用同一套代码，仅语言文件不同

## 六、提交步骤

1. 注册/登录 [mcmod.cn](https://www.mcmod.cn)
2. 顶部「模组」→ 搜索 `道法自然`，确认不存在同名词条
3. 点「创建模组词条」
4. 按本文第一节填基本信息，第二节填短简介，第三节填正文
5. 上传图标（`docs/logo-128.png`）与截图
6. 提交，等待编辑审核（通常几天内）

> 审核可能会让你补充：下载链接的直链、依赖模组版本、封面图尺寸。按编辑要求补即可。
